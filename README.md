#AP Election Dashboard 2024
##An interactive, visual Power BI dashboard built to analyze the 2024 Andhra Pradesh Legislative Assembly Elections—featuring insights into party performance, voter trends, constituency-level results, and more.
#Dataset used
<a href="https://github.com/naveen-pogiri18/AP-election-dashboard/blob/main/Ap%20election%20dataset.xlsx"> Ap election 2024 data</a>
#Tech Stack
##The dashboard was built using the following tools and technologies:
##Power BI Desktop – Main data visualization platform used for dashboard development.
##Power Query – Used for data transformation, cleansing, and shaping election datasets.
##DAX (Data Analysis Expressions) – Used to create calculated fields, dynamic metrics, and conditional formats.
##Data Modeling – Relationships established between parties, constituencies, candidates, and voting data for accurate visual representation.
#Data Source
##Source: Official Election Commission of India, news portals, public datasets, and scraped constituency-wise results.
##Structure:
##Constituency Details (Code, Name, District)
##Candidate Info (Name, Party, Gender)
##Total Votes, Vote Share (%), Margin of Victory
##Voter Turnout (Male, Female, Total)
##Winning Party per Constituency
